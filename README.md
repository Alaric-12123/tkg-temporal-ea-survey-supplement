# Supplementary materials: Temporal Modeling for Entity Alignment in Temporal Knowledge Graphs

Supplementary Tables S1 and S2 for the survey *Temporal Modeling for Entity Alignment in Temporal Knowledge Graphs: A Survey and Taxonomy* (HaiJie Yang, Beijing Information Science and Technology University).

| File | Content |
|---|---|
| `Supplementary_Table_S1_Taxonomy.csv` / `.xlsx` | Four-layer (L1–L4) operational taxonomy of the 43 core methods; the workbook also contains operation-level traces for six methods and a field guide |
| `Supplementary_Table_S2_Evidence.csv` / `.xlsx` | 67 mechanism–evidence records: intervention, surviving temporal paths, reported values, supported inference and limitations |
| `supplementary_source_mapping.csv` | Source of every record (coding record, original-paper locator, bibliography) |
| `DETAILED_README.md` | Definitions, scope, evidence states and source precedence |
| `supplementary_validation_report.md` | Checks performed and their scope |

The tables are derived from published papers; no new experiments were run. Reported values are copied from the original papers with their scale stated in `Numeric Unit`; they are not comparable across papers without matching the conditions listed in each row. Original papers are not redistributed here.

AI assistance in preparing these tables is described in the manuscript's AI-use statement.
